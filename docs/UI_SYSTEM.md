# UI system

## Visual direction

HomeServe uses an original, service-first design language: deep teal for trust, warm amber for attention and generous neutral surfaces for operational clarity. The marketplace is editorial and reassuring; dashboards are dense enough for real work without feeling like generic admin templates.

## Core tokens

- Brand: `#0b6b63`
- Brand dark: `#074943`
- Brand tint: `#dff3ef`
- Ink: `#152a2d`
- Muted text: `#65777a`
- Border: `#dfe8e6`
- Surface: `#f4f8f7`
- Accent: `#f0a43c`

Typography uses Manrope for display and DM Sans for interface copy.

## Reusable patterns

- Service cards combine visual context, provider trust, duration, location and price.
- Status badges use the same vocabulary across customer, provider and admin views.
- Booking uses a focused two-step drawer to preserve marketplace context.
- Dashboard panels share heading, table, metric and empty-state primitives.
- Controls use 44–54 px target heights and visible focus-compatible borders.

## Responsive behavior

- Four-column service categories collapse to two and then one.
- Marketplace filters move above results on tablets.
- Dashboard navigation becomes an off-canvas sidebar.
- Tables remain horizontally scrollable rather than dropping critical fields.
- Booking becomes a full-width sheet on small screens.
